## 📌 What is Continuum?

Continuum (formerly Boris Continuum Complete / BCC) is a **plugin suite of visual effects tools**, not a standalone editor — it installs directly into host applications like Adobe Premiere Pro, After Effects, Avid Media Composer, DaVinci Resolve, and OFX-compatible hosts. Developed by Boris FX (founded 1995, and later merging with GenArts' Sapphire and other acquired tools), it's widely used in broadcast, film, and episodic television post-production.

| Feature                     | Description                                                    |
| ------------------------------- | ---------------------------------------------------------- |

| Particle Illusion                | Real-time particle effects for fire, smoke, magic, and more          |
| Title Studio / 3D Objects          | 3D text and object creation directly inside the host timeline          |
| Beauty & Skin Retouching           | AI-assisted face and skin smoothing for interviews and talent            |
| Lens Flares & Optical Effects       | Physically-based lens flares, glows, and film-look effects                 |
| Mocha Planar Tracking                | Industry-standard planar tracking and rotoscoping tools                     |
| Image Restoration                     | Dust busting, noise reduction, and de-flicker for archival footage           |
